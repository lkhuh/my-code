# Legacy Pygame Experiments

These are archived learning projects moved out of the School Question Paper Generator repository so each repository has a clear purpose.

- `snake_game_legacy.py` — early Snake game experiment
- `pong_game_legacy.py` — early Pong game experiment

## Before running

These scripts use machine-specific Windows paths for images and audio. Those assets are not included in this archive, so the scripts will need their file paths replaced with local/relative asset paths and the original assets supplied before they run. They are preserved as source, not presented as polished releases.
