# My Code Archive

A personal collection of code, experiments, and projects I've worked on while learning and building with software.

## About this repository

This repository is my long-term coding archive. It brings together work from different stages of my programming journey, so some files may be small experiments or works in progress rather than polished, standalone applications.

## Exploring the code

- Browse the repository files to see the individual experiments and projects.
- Check each project's files for its specific requirements and instructions.
- If a project has its own README, use that as the source of setup and usage details.

## Status

This is an evolving archive. I plan to improve project descriptions, organization, and documentation as I revisit older work.
