# Python Code Archive

A long-term archive of Python learning exercises, experiments, and older projects from different stages of my programming journey. Not every file is a polished or independently runnable application.

## Organized sections

- **[Legacy games](legacy-games/)** — older Pygame Snake and Pong experiments. They reference local media files that are not included.
- **[Practice snippets](practice/)** — small experiments, including exception handling, regular expressions, and file I/O.
- **[Legacy exercises](practice/legacy-exercises/)** — older standalone scripts moved out of the repository root to keep the archive organized.

## How to explore

Read the relevant folder README first. Individual scripts may need dependencies, input files, or path updates. For polished/current projects, see the [developer portfolio](https://lkhuh.github.io/).

## Archive maintenance

This repository preserves historical learning work; some examples and filenames are old. Avoid committing credentials, personal records, generated bytecode, or unrelated project files.
